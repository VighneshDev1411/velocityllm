Renders a single Lucide icon glyph; use anywhere the product shows an icon (nav, buttons, stat cards, status dots).

```jsx
<Icon name="zap" size={16} color="var(--color-primary)" />
```

Requires the Lucide CDN script (`<script src="https://unpkg.com/lucide@latest"></script>`) to be loaded on the page — every UI kit and card in this system already includes it. Icon names match https://lucide.dev exactly (kebab-case). Common names used across VelocityLLM: `layout-dashboard`, `flask-conical`, `bar-chart-3`, `activity`, `cpu`, `briefcase`, `radio`, `coins`, `key`, `credit-card`, `gauge`, `zap`, `webhook`, `shield`, `users`, `settings`, `chevron-down`, `log-out`, `user`, `check-circle`, `alert-circle`, `refresh-cw`, `dollar-sign`, `clock`.
