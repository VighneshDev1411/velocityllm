Sticky bar above the page content, next to the sidebar. Shows the current page title (left) and profile avatar (right).

```jsx
<TopBar title="Dashboard" userInitial="A" userName="admin" />
```

Blurred glass background (`rgba(19,19,19,0.6)` + 16px blur) — always pair with `Sidebar` inside an `AppShell`-style flex layout (see `ui_kits/console`).
